# Welcome to my blog

is this a new blog? 

This is my personal blog. Posts are written in **Markdown** and stored right in the repository under `docs/blog/posts/`, so they show up here automatically whenever I push a new file.

## What to expect

- Notes about code and software
- Linux tips and tricks
- Adventures in the open source world

## How it works

This page reads the `blog/posts` directory from the GitHub repository, renders each `.md` file, and shows them newest first. No build step needed.

> Tip: create a file like `2026-08-05-my-title.md` in the `posts` folder and it appears here.

```bash
git add docs/blog/posts/
git commit -m "new post"
git push
```
