### How this blog works (for curious devs)

```bash
# 1. create a post
echo "# My new post\n\nHello world!" > docs/blog/posts/2026-09-15-my-new-post.md

# 2. update the static DB (no backend needed)
npm run update:data
# -> generates docs/data/posts.json, youtube.json, db.json

# 3. commit & push -> GitHub Pages deploys
git add docs/blog/posts docs/data
git commit -m "new post: my new post"
git push
```

Frontend fetches `../data/db.json` first, then falls back to live APIs only if needed. Fully static, fast, and version-controlled.
