### Structure

```
├── docs/               # Website source (deployed to GitHub Pages)
│   ├── index.html      # Home / gallery (hero: Python/AI/Docker/Linux/IoT)
│   ├── about/          # About — fullstack Python AI + IoT bio
│   ├── projects/       # Projects — live GitHub API
│   ├── blog/
│   │   └── index.html  # Videos (YouTube, per-request update)
│   ├── data/           # Static DB fallback (generated, no backend)
│   │   ├── youtube.json # Videos from @al3x_argu (fallback)
│   │   └── db.json      # Combined (youtube + site)
│   ├── css/theme.css   # Dark theme, glass, responsive
│   └── js/i18n.js      # i18n engine (code in English)
├── scripts/
│   └── update-data.js  # Generates youtube.json/db.json (English code)
└── .github/workflows/update-data.yml  # Weekly YouTube refresh
```

### Run locally

```bash
python3 -m http.server 8000 --directory docs
# or
npm run serve
```

### Data — no backend, per-request update

YouTube (`@al3x_argu`, `UCVgabwEiFAunNH6c7abqoCQ`) via `https://www.youtube.com/feeds/videos.xml?channel_id=...` is fetched **live on every request**. Static `youtube.json`/`db.json` are only fallbacks.

```bash
npm run update:data
# or
node scripts/update-data.js
# -> docs/data/youtube.json, db.json (fallback)
```

Frontend: `live RSS (api.allorigins.win) -> fallback to ../data/db.json -> ../data/youtube.json` — database updated on every request.
